# cad/drone_frame

Custom mounting plates and brackets for the Tarot FY690S hex frame.

The primary frame is the **Tarot FY690S** (off-the-shelf, no custom design needed).
This folder holds any custom adapter plates for mounting the Pi, sonar, and sensor board.

## Files to Add

| Filename | Format | Description |
|---|---|---|
| `pi_mounting_plate.stl` | STL | Centres Pi 4 on top frame plate with M3 standoffs |
| `sonar_centre_mount.stl` | STL | Holds HC-SR04 pointing straight down, clears claw arms |
| `pi_mounting_plate.f3d` | Fusion 360 | Editable source |
| `sonar_centre_mount.f3d` | Fusion 360 | Editable source |

## Frame Reference

| Spec | Value |
|---|---|
| Wheelbase | 690mm |
| Arm tube OD | 16mm |
| Centre plate hole pattern | M3, various spacings |
| Max all-up weight | ~3000g |

## Print Settings

| Setting | Value |
|---|---|
| Material | PETG |
| Infill | 40% |
| Layer height | 0.2mm |
