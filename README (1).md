# cad/camera_mount

Forward-facing Pi Camera v2 bracket for the Tarot FY690S front arm (16mm tube).

## Requirements

- Clamps to 16mm OD front arm — split clamp with 2x M3 bolts
- Holds Pi Camera v2 facing forward at 5–10° downward tilt (fixed, not adjustable)
- Camera must be level side-to-side — verify with spirit level after mounting
- CSI ribbon must have a clean path back to Pi with no bends tighter than 5mm radius
- Add thin foam pad between camera PCB and bracket to damp vibration
